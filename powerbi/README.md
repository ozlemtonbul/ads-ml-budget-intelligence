# Power BI Integration

This project supports Power BI reporting through:

- CSV exports generated by the Python analytics pipeline
- PostgreSQL data warehouse integration
- Scheduled refresh-compatible reporting datasets

## Supported Data Flow

Google Ads + Google Analytics 4
→ Python Analytics and AI Pipeline
→ CSV / Excel / PostgreSQL
→ Power BI Dashboard

A production PBIX file is not included because dashboards may contain company-specific data and credentials.

Power BI Desktop can connect either to exported CSV files or directly to PostgreSQL.
